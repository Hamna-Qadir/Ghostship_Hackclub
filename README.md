👻Catch The Ghost!

A browser-based project built using p5.js during the Hackclub Ghostship workshop.


How to play
   - Use your trackpad/ mouse to follow the ghost and catch it by clicking on it
   -  You have 30 seconds to try to catch the ghost as many times as you can, but       watch out it can move around your screen pretty fast.

Built with
  - p5.js
