<h1> 👻Catch The Ghost! </h1>

A browser-based project built using p5.js during the Hackclub Ghostship workshop.


<h2> How to play </h2>
Use your trackpad/ mouse to follow the ghost and catch it by clicking on it
You have 30 seconds to try to catch the ghost as many times as you can and increase your score!

<h2> Built with </h2>
  - p5.js
