<h1> 👻Catch The Ghost! </h1>
A browser-based game built using p5.js during the Hack Club Ghostship workshop.


👾 Play it here: https://hamna-qadir.github.io/Ghostship_Hackclub/


<h2> How to play </h2>
Use your trackpad/ mouse to follow the ghost and click on it to catch it.
You have 30 seconds to catch the ghost as many times as you can and rack up your score!

<h2> Built with </h2>


  - p5.js  

  - HTML, CSS, and JavaScript
